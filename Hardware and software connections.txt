Hardware Connections
1. TCS34725 Color Sensor → ESP32
TCS34725 Pin	ESP32 Pin
VCC / VIN	3.3V
GND	GND
SDA	GPIO 21
SCL	GPIO 22

The TCS34725 communicates with the ESP32 using the I²C protocol.

2. DHT11 Temperature & Humidity Sensor → ESP32

The current Arduino code uses GPIO 4 for the DHT11 data pin.

DHT11 Pin	ESP32 Pin
VCC	3.3V
DATA	GPIO 4
GND	GND

If using a bare DHT11 sensor, connect a 10 kΩ pull-up resistor between DATA and 3.3V. If using a DHT11 module, the resistor is generally already included.

3. MAX30102 → ESP32

For actual heart-rate and SpO₂ measurements, the MAX30102 can be connected as follows:

MAX30102 Pin	ESP32 Pin
VCC / VIN	3.3V
GND	GND
SDA	GPIO 21
SCL	GPIO 22

The MAX30102 and TCS34725 can share the same I²C bus because both communicate through SDA and SCL.

4. Complete ESP32 Wiring
ESP32	Connected Component
3.3V	TCS34725 VCC
3.3V	DHT11 VCC
3.3V	MAX30102 VCC
GND	TCS34725 GND
GND	DHT11 GND
GND	MAX30102 GND
GPIO 21	TCS34725 SDA
GPIO 21	MAX30102 SDA
GPIO 22	TCS34725 SCL
GPIO 22	MAX30102 SCL
GPIO 4	DHT11 DATA
5. ThingSpeak Connection

ThingSpeak does not require a physical wire connection. The ESP32 connects to ThingSpeak through Wi-Fi.

The complete data flow is:

TCS34725 + DHT11 + MAX30102 → ESP32 → Wi-Fi → ThingSpeak → MATLAB → CF Prediction

ThingSpeak Channel Fields
Field	Parameter
Field 1	Chloride Level
Field 2	Humidity
Field 3	SpO₂
Field 4	Heart Rate
Field 5	CF Prediction
